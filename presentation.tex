\begin{frame}[t]{Task 2.1: Why this visualization supports the task}

\begin{itemize}\setlength\itemsep{8pt}
  \item \textbf{Scatterplot for Correlate:} Position is the most accurate visual channel for two quantitative attributes. A visible trend or spread in the point cloud directly answers the \textit{Correlate} characteristic.

  \item \textbf{\texttt{scaleSqrt} for circle size:} We perceive area, not radius. A linear radius scale makes a $4\times$ data value appear $16\times$ visually. \texttt{scaleSqrt} makes area grow linearly — honest encoding of review count.

  \item \textbf{\texttt{d3.extent} for y-axis:} Ratings span only 7.7–8.7. Starting at 0 compresses all variation into the top 10\% of the chart.

  \item \textbf{No colour in Task 2.1:} There are no groups to distinguish. Colour here would imply structure that does not exist.

  \item \textbf{No grid lines:} The task is pattern detection, not precise reading. Grid lines add clutter without helping \textit{Correlate}.
\end{itemize}

\end{frame}

\begin{frame}[t]{Task 2.2: Why this visualization supports the task}

\begin{itemize}\setlength\itemsep{8pt}
  \item \textbf{LDA for Compare + Group:} LDA is supervised — it finds the projection that \textit{maximally separates} labelled groups. PCA would not guarantee group separation. This directly serves \textit{Compare + Group}.

  \item \textbf{Feature normalisation:} \texttt{year} ($\approx$2010) vs.\ \texttt{minplayers} ($\approx$2) differ by $1000\times$. Without normalisation LDA is dominated by year. All features scaled to [0,\,1].

  \item \textbf{Colour legend — included:} Without it, the three groups are unidentifiable.

  \item \textbf{Tooltip — included:} 100 overlapping circles; without it no individual game can be named.

  \item \textbf{Variable circle size — excluded:} No meaningful 3rd attribute in this view. Variable size would add noise without encoding anything real.
\end{itemize}

\end{frame}

\begin{frame}[t]{Task 2.3: Interacting with LDA Parameters}

\begin{columns}[T]
\column{0.54\textwidth}
  \textbf{Interactions implemented:}
  \begin{enumerate}\setlength\itemsep{6pt}
    \item \textbf{Dual-handle rank cutoff slider}\\
          Colour-coded track (blue/orange/red). Text inputs for precise entry. Labels show exact ranges in real time.

    \item \textbf{Year range preset buttons}\\
          All / 2000+ / 2010+ / Custom.\\
          98 of 100 games are from 2002--2021; a continuous slider would span 145 years (Crokinole, 1876) and be unusable.

    \item \textbf{Category \& Mechanics filters}\\
          Checkbox lists with live search, applied server-side before preprocessing.
  \end{enumerate}

\column{0.42\textwidth}
  \textbf{Why low interaction cost?}
  \begin{itemize}\setlength\itemsep{4pt}
    \item Slider drag \textbf{or} text field to set cutoffs
    \item One click: \textbf{Run LDA}
    \item Result updates in the same view — no reload
  \end{itemize}

  \vspace{6pt}
  \textbf{Why rank cutoff is the key parameter:}\\
  \small LDA is supervised — class labels are its most important input. Changing them redefines what ``top'' means. Top~$\le$~10 asks a different question than Top~$\le$~50.
\end{columns}

\end{frame}
